## About

I'm a **Full-Stack Mobile Developer** based in Chiniot, Punjab, Pakistan, focused on building **production-grade mobile applications** that combine clean native engineering with real-time computer vision and reliable backend infrastructure.

My work spans the full delivery cycle — from native Android and cross-platform architecture to Python-based ML processing and secure, multi-role database systems — built to hold up in production, not just demo well.

**Core Focus**

```text
• Cross-Platform Mobile Development (Flutter / Dart)
• Native Android Engineering (Kotlin / Jetpack Compose)
• Computer Vision Pipelines (YOLOv8 / OpenCV)
• Python Media Processing & REST API Backends
• Real-Time Sync & Row-Level Security (Supabase / Firebase)
• Freelance Product Delivery for Global Clients
```
