## Featured Projects

### 🎬 FlashCut AI
**AI-powered video highlight extraction — production app**
`Kotlin` `Jetpack Compose` `Python Flask` `YOLOv8` `OpenCV` `Oracle Cloud`

Automates sports highlight discovery: raw match footage is uploaded from a native Android client, processed by a Python backend running computer vision models, and returned as auto-generated highlight cuts.

### 🏥 Clinic Management System
**Multi-role medical workspace platform — desktop & tablet**
`Flutter` `Supabase` `Realtime Sync` `Row-Level Security`

Built for live clinical use across Windows desktop and Android tablets. Separate role-based modules for receptionists, doctors, and pharmacists, all kept in sync through a shared real-time database.

### 🌐 HostMeerkat
**Hosting agency web portal**
`Bootstrap 5` `JavaScript` `PHP`

A fully responsive hosting company site with performance-tuned pages, light/dark theming, and polished UX components.

### 💼 20+ Freelance Projects Delivered
`Full-Stack Development` `Agile Delivery` `Client Communication`

Three years of scoping, building, and shipping custom web and mobile products for clients worldwide — turning business requirements into working software.
